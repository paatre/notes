# Networking

## WWAN

WWAN (Wireless Wide Area Network) is a wireless network that connects to the internet through a cellular network. It is also known as a mobile broadband network. WWAN is different from WLAN (Wireless Local Area Network) and WPAN (Wireless Personal Area Network) as it covers a larger area. A device needs a WWAN card to connect to the WWAN network. Typically, the device also needs a SIM card to connect to the WWAN network. The SIM card is used to authenticate the device on the network and is issued by the network provider/mobile carrier.

## LAN

LAN (Local Area Network) is a network that typically connects devices to a same network in limited areas such as homes, offices, and public places like cafes, airports, and hotels. You can usually share resources like files between devices on a LAN network. You can also connect the devices from a LAN to the internet via a router. Nowadays a router actually has multiple functions like a router, a modem, a gateway, a wireless access point.

### Router

A router's main function is to route data packets within a network, such as the LAN, to the correct devices. It does this by using the IP address of the devices.

### Modem

Modem stands for Modulator-Demodulator and it is a device that converts digital data into analog data and vice versa. That means it converts the digital data from a computer into analog data that can be transmitted over a line and then converts the analog data back into digital data at the receiving end.

You need modem to connect a network to the internet because the data between different networks travel by different types of analog lines so a way to convert the data between analog and digital formats is needed. This is usually done by ISPs (Internet Service Provider) with a wired modem. A wired cable such as a coaxial cable, a DSL cable, or a fiber optic cable is connected to the modem. The modem then connects to the router, which connects to the LAN network.

### Gateway

Whereas a modem handles the physical signal conversion between analog and digital data, a gateway is a device that connects two different networks in a more software way, translating data between different protocols etc. Typically it's used as router between a LAN network and the internet. Network traffic from the LAN network is sent to the gateway, which then sends it to the internet. The gateway also receives data from the internet and sends it to the LAN network.

### Wireless Access Point

A wireless access point is a device that allows wireless devices to connect to a wired network using Wi-Fi. It is usually connected to a router. A wireless access point can also be used to extend the range of a WLAN network by connecting to another wireless access point. This is called a wireless mesh network.

## WLAN

WLAN (Wireless Local Area Network) is a wireless LAN. This means that it is a LAN network that connects devices wirelessly. It serves the same purpose as a LAN network but without the need for cables. WLAN networks are usually secured with a password to prevent unauthorized access.

### Wi-Fi

Wi-Fi is a technology that allows devices to connect to a WLAN network wirelessly. It is a trademark of the Wi-Fi Alliance, which is a group of companies that develop and certify Wi-Fi products. So even though WLAN and Wi-Fi are usually used interchangeably, Wi-Fi is actually a specific technology that allows devices to connect to a WLAN network. So Wi-Fi is a type of WLAN. Other types of WLAN networks include Bluetooth and Zigbee.
